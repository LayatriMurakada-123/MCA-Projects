### 2. 🤖 AI Chatbot for ICET Rank & College Prediction System

An **AI-powered chatbot and college prediction system** that helps ICET candidates understand their expected rank and identify suitable colleges based on rank, course preferences, fees, and location.

The project follows an **Agentic AI-style architecture**, where different agents perform specific tasks and work together to generate a recommendation.

#### 🔹 Features

* ICET score to expected rank prediction
* College prediction based on rank
* Course preference matching
* Fee-based filtering
* City/location-based filtering
* AI chatbot interface
* College directory
* REST APIs
* Agent-based processing
* Explanation of prediction results
* Responsive web interface

#### 🤖 AI Agents

The system contains multiple specialized agents:

| Agent                  | Responsibility                                    |
| ---------------------- | ------------------------------------------------- |
| **Rank Agent**         | Converts ICET score into an indicative rank range |
| **College Agent**      | Finds colleges based on expected rank             |
| **Preference Agent**   | Matches course, fees, and city preferences        |
| **Explanation Agent**  | Generates an understandable explanation           |
| **Agent Orchestrator** | Coordinates the complete workflow                 |

#### 🛠️ Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python, Flask
* **Database:** SQLite / SQL
* **API:** REST API
* **AI Concept:** Agentic AI
* **Tools:** VS Code, Git, GitHub

## 🚀 How to Run the Projects

### Prerequisites

Make sure the following are installed:

* Python 3.x
* VS Code or any code editor
* Git
* Web browser

### Clone the Repository

```bash
git clone https://github.com/your-username/mca-projects.git
cd mca-projects
```

### Run a Project

Navigate to the required project folder and create a virtual environment:

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r backend/requirements.txt
```

Run the Flask application:

```bash
python backend/app.py
```

Then open the URL displayed in the terminal, usually:

```text
http://127.0.0.1:5000
```
