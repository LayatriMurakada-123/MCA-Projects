# AI Chatbot for ICET Rank and College Prediction using Agentic AI

## Project Overview
The AI Chatbot for ICET Rank and College Prediction is an intelligent web application designed to help students explore suitable colleges based on their ICET rank and admission preferences. It provides an interactive chatbot interface to simplify the college selection process.

## Objectives
- Assist students in finding suitable colleges based on their ICET rank.
- Provide an interactive chatbot for college-related queries.
- Simplify the college selection and admission guidance process.
- Organize college information for easier access.

## Features
- Interactive AI chatbot interface.
- ICET rank-based college prediction.
- College information and recommendations.
- User-friendly web interface.
- Database integration for storing and retrieving information.

## Technologies Used
- **Programming Language:** Python
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **Database:** SQL (if configured)
- **AI:** Agentic AI / LLM integration (as implemented)

## Installation and Setup
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Install the required Python dependencies:

   ```bash
   pip install -r backend/requirements.txt
   ```

4. Configure any required environment variables or API keys.
5. Run the application using the entry point specified in the project.
6. Open the local URL displayed by the application in your browser.

## Expected Outcome
The application helps students explore college options based on their ICET rank and makes admission-related information easier to access.

## Future Enhancements
- Integration with updated college and cutoff data.
- Improved rank-based recommendations.
- More conversational AI capabilities.
- Additional admission filters and student preferences.

# Hostel Information Database Management System

## Project Overview
The Hostel Information Database Management System is a database-oriented project designed to manage hostel-related information efficiently. It helps organize student details, room allocations, and other hostel records in a structured database.

## Objectives
- Maintain student and hostel records systematically.
- Manage room allocation information.
- Reduce manual record-keeping.
- Improve the organization and retrieval of hostel data.
- Maintain data consistency using database concepts.

## Features
- Student information management.
- Hostel and room details management.
- Room allocation records.
- Structured storage and retrieval of information.
- Database operations using SQL.

## Technologies Used
- **Database:** MySQL
- **Query Language:** SQL
- **Concepts:** Database Design, Relational Tables, Primary Keys, Foreign Keys, CRUD Operations

## Database Components
Depending on the implemented schema, the database may include:
- Student details
- Hostel details
- Room details
- Room allocation information

## Installation and Setup
